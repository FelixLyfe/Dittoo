# Clipboard palette

The palette opens on the screen under the pointer and remembers the previously active application as
the paste target. Search is focused on open. Arrow keys move selection; Return pastes; Command-Return
copies; Option-Return pastes while keeping the window open; Command-period pins; Command-P opens the
type filter; Command-K opens actions; Escape closes.

The menu exposes only About and Settings. There is no launcher mode or feature switcher.
